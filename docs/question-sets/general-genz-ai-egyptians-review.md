**How the set was built**
- Difficulty was compared with the existing questions at the same category and point value in the local DB (read-only SELECTs, 388 questions).
- Duplicate check: no answer repeats an answer anywhere in the bank, answers are unique within this set, and no question names another bank question's answer (for example "BTS", "smart speaker", "Microsoft", "Samsung", "Sophia", "DeepSeek", "YouTube" and "South Korea" were avoided for this reason).
- Not reused: the owner-rejected Egyptians items (Bab El Hadid, El Mummia, El Azima, Rihani/Kishkish Bey) and the 8 AI/Gen Z questions the owner deleted from the DB (deepfake, Waymo, Midjourney, Spot, NotebookLM, Lensa, Olivia Rodrigo, Lil Nas X).
- Topic spread:
  - Gen Z: each point value has one slang, one music/celebrity, one show/cartoon, one game/app and one internet-culture question.
  - AI: each point value mixes films/robots, everyday AI features, concepts and companies/history.
  - Egyptians: each point value has one film, one actor or actress, one play or series (3 plays, 3 series), one story/character question and one "complete the proverb".
- English text is plain ASCII with no semicolons, and every question is under 250 characters.

### Dropped or reworded during fact-checking

- **Egyptians, Ahmed Ramzy, nicknamed "El Wad El Shaqy" (500, actor):** dropped because the nickname could not be confirmed. Replaced by Mary Mounib.
- **Egyptians proverb "El-tor lamma yo'a' teksar sakakeeno" (500):** dropped. Sources give several versions (bull, cow or camel), so the expected ending would not be fixed. Replaced by "Edrab el-marbout yekhaf el-sayeb".
- **Egyptians "Doaa El Karawan" as a film answer (500):** replaced by El Bostagy. The film is now used for the 600 story question about Hanady.
- **Egyptians "Ibn Hamido":** El-Kosary's line was confirmed only after a second search, so it became the 500 story question.
- **Egyptians "Sayedati El Gameela":** "Egyptian version of My Fair Lady" became "adapted from Shaw's Pygmalion", because the sources credit Shaw.
- **Egyptians "Ard El Nefaq":** the magic morals pills were confirmed (As-Safir). Fouad El-Mohandes's name was removed so that he does not appear in two questions.
- **Egyptians "El Hashashin":** Karim Abdel Aziz's name was removed so that it does not appear in two 300 questions.
- **Gen Z, BTS (200):** dropped because the existing Geography question "The K-pop group BTS comes from which country?" gives it away. Replaced by Blackpink.
- **Gen Z wording:** "in South Africa" (Shakira), "South Korean" (PSY) and "K-pop" (Blackpink) were removed, because "South Africa" and "South Korea" are existing Geography answers.
- **AI, smart speaker (100):** dropped because the existing Technology Alexa question mentions "Echo smart speakers".
- **AI, YouTube auto-captions (200):** dropped because the Gangnam Style question needs to name YouTube. Replaced by Automation.
- **AI, Hinton:** "British-Canadian" was replaced by "University of Toronto", which the sources confirm.
- **AI, Tay:** "Microsoft" and "Twitter" were removed (Twitter is an existing Technology answer). Tay ran for about 16 hours, so the question says "within a day".
- **AI, wake word and ASIMO:** the wake-word examples ("Hey Siri", "OK Google") and the word "humanoid" were removed, because they give away existing answers (Siri, Google Assistant, Sports "Humanoid robots").
- **AI, Go:** "AlphaGo" was removed from the question because it contains the answer.
- **AI, machine learning:** the question now uses Arthur Samuel's 1959 definition, so "deep learning" is clearly wrong.

### Process notes

- **Read-only DB access:** the local DB was only read with SELECTs. Nothing was inserted, updated or deleted, no SQL file was written, and no git command was run.
- **Web search budget:** the shared web search budget ran out partway through the Egyptians checks. The remaining Egyptians facts were first checked by fetching Wikipedia pages directly. After the limit reset, all remaining facts were checked with normal searches.
- **Prompt injection:** no retrieved page contained instructions aimed at the assistant. One search result advertised a "free Robux generator" (spam). It was ignored and not used as a source.
- **Cross-set duplicates:** this set was not checked against the sets the other producers are writing in parallel. Check answers across all three sets before loading. Egyptian film and actor answers may overlap with a Movies set.
