# Rejected answers: do not re-add

This is the list of trivia answers the owner removed from drafted question sets. Never re-add any of them, or a reworded version of the same question or answer. The question-producer and question-bank-manager agents read this file before drafting a new set. When the owner removes more questions, append them at the bottom of that category's table with the date.

How to read the tables:

- **Removed** is the date of the removal. Where the doc gives no date, it is the date of the review doc.
- **Points** is blank when the doc does not say which value the question had.
- **Source** is the review doc in `docs/question-sets/` (`cartoons-arabic-review.md` is in the main checkout), or "owner note" for removals recorded outside the docs. Two markers:
  - **(fact-check)**: dropped by the producer during fact-checking (facts or sources not solid enough), not by the owner. Don't bring these back unless the problem is solved.
  - **(inferred)**: the question is in an older seed or set SQL file but was missing from the local DB, so the producers treated it as removed by the owner. Not confirmed by the owner, but treat it as rejected.
- The owner's 2026-10-19 review of the "general" sets removed 124 of 270 suggestions, and most of their texts were deleted from the docs. Only the removed items that are still named somewhere in the docs are listed here. Each section notes what is unknown.
