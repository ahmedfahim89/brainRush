## Developer decisions (for the PO)

None contradicts an acceptance criterion. Decisions 1 and 9 are the ones to confirm.

1. **The setting is taken at game start** (like `helpers_enabled`). US-44 reads "Given the setting is on, when the host ends the game". A game started before the admin switched it on does not offer the round, and one started before it was switched off still does. The Admin hint says "in new games". In practice the value is read when Setup loads, so a Setup page left open for hours can be stale (BUG-9-01). The PO should confirm "new games only" is what the owner wants.
2. **"Largest enabled point value" is the largest value on this game's board.** Matches D-48 (read from the enabled values, never hard-coded) and tested with 400, 500 and 600. A running game keeps its board's value even if the admin changes the point values meanwhile.
3. **The question is drawn when Play final round is clicked**, so the category can be shown first. Its text is kept off the page until Show the question, but it is in `localStorage` from then on. Fine for a shared-screen party game, like the wagers.
4. **Several contestants can be Correct** (the AC says only "every contestant is scored once"; D-08's one-winner rule is for board cells).
5. **See results waits until everyone is marked.** On the website there is no other way out of the round once the question is open (no Skip, Back or Leave); a host who cannot score someone must mark them Wrong. In the app, Back offers it with a confirm. Consistent with "every contestant is scored once", but the PO may want a web "stop the round" later.
6. **Masking uses a text field with `-webkit-text-security`, plus a Show button.** The AC says wagers are masked and hidden; Show reveals the digits to the person typing only, and is masked again for the next one. A wager cannot be changed once locked.
7. **The final question's timer restarts at full length after a refresh** (D-04); wagers and marks are kept, as the AC asks.
8. **No helpers and no double score on the final question**; Pause, Reset, Show Answer, the language button and Report work as on the board.
9. **The "Read questions automatically" choice is stored on the device** (`localStorage`), not as an Admin setting. US-48 says only "a setting"; the sprint plan assumed an on-device preference and asked the PO to confirm. It means each device or browser must tick it once, and an admin cannot turn it on for everyone.
10. **The speaker reads choice letters as "A: ..."**, also in Arabic.

## Bugs and findings

**BUG-9-01 FIXED, verified in the re-test (RT1 to RT5).
