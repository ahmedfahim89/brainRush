## Known limitations

- From 801 to about 980 px, showing the 3 columns still makes the table scroll sideways (unchanged from FU-44).
- At 1365 px the compact rows (median 82) are a little lower than at 1366 px (median 90). This edge is intended.
- Headless Chrome only gives whole-pixel viewports, so a width such as 1365.5 px could not be tested. At such a width the query `max-width: 1365px` does not match, so the full 10-column table and no button apply together, which is consistent. The 800 / 801 edge uses the complementary query as before.
- The toggle state is still not remembered across page loads.
