Game settings

For example: New questions added in Egyptians category — try it now!

When on, players see a "back within 24 hours" popup instead of the game.

When off, the helper buttons are hidden for new games. A game already in progress keeps its helpers.

When on, and 2 or more players are tied for first when a new game ends, End Game asks "It's a tie! Golden Goal?" ("Go for goal" or "Skip to results"). Everyone bets from 0 up to their score or the largest point value, whichever is higher. Rounds repeat while the tie lasts. With no tie, the results show as usual.

From AdSense: Account > Account information (publisher ID) and Ads > By ad unit > Display ads (slot ID). On this computer (localhost) ads run in test mode.

    Reports

    Problems players reported from the game, grouped by question, the most reported first. Fix the question with Edit question, then Resolve its reports; Dismiss junk. Both keep the reports in the database but take them off this list. A report holds only the reason, the note and the time.
